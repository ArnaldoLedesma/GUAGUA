# 👶 Sistema de Gestión GUAGUA

Sistema de gestión desarrollado para una pañalera, orientado a facilitar la administración de productos, stock y operaciones comerciales.

El proyecto fue desarrollado como una solución de software utilizando Python, incorporando una interfaz gráfica y persistencia de datos mediante SQLite.

## 💻 Tecnologías utilizadas

- Python
- SQLite
- CustomTkinter
- Git
- GitHub
- Visual Studio Code

## ⚙️ Funcionalidades

El sistema incorpora funcionalidades orientadas a la gestión del negocio, entre ellas:

- Gestión de productos
- Control y consulta de stock
- Registro y consulta de información
- Interfaz gráfica de usuario
- Persistencia de datos mediante SQLite

## 🗂️ Estructura del proyecto

- `main.py` → punto de inicio de la aplicación
- `ventana_principal.py` → interfaz principal del sistema
- `base_datos.py` → gestión y conexión con la base de datos
- Archivos `.png` e `.ico` → recursos gráficos utilizados por la aplicación

## 🔒 Privacidad de los datos

La base de datos utilizada por la aplicación no se incluye en este repositorio para preservar la confidencialidad de la información.

Los archivos de datos, entornos virtuales y archivos temporales son excluidos mediante `.gitignore`.
